# Пошаговая инструкция после установки GTK3

## ✅ Шаг 1: Проверьте путь установки GTK3

После установки GTK3 найдите папку `bin` внутри директории установки:
- Обычно: `C:\Program Files\GTK3-Runtime Win64\bin`
- Или: `C:\Program Files (x86)\GTK3-Runtime Win64\bin`

Убедитесь, что в этой папке есть файлы:
- `libgobject-2.0-0.dll`
- `libgtk-3-0.dll`
- `libcairo-2.dll`

## ✅ Шаг 2: Добавьте путь в PATH

### Способ 1: Через настройки Windows (рекомендуется)

1. Нажмите `Win + X` → выберите "Система"
2. Или: `Win + R` → введите `sysdm.cpl` → Enter
3. Перейдите на вкладку **"Дополнительно"**
4. Нажмите **"Переменные среды"** (внизу справа)
5. В разделе **"Системные переменные"** найдите переменную `Path`
6. Выберите `Path` → нажмите **"Изменить"**
7. Нажмите **"Создать"** (New)
8. Вставьте путь к `bin` директории GTK3:
   ```
   C:\Program Files\GTK3-Runtime Win64\bin
   ```
9. Нажмите **"OK"** во всех окнах

### Способ 2: Через PowerShell (от администратора)

```powershell
# Откройте PowerShell от имени администратора
# Замените путь на ваш реальный путь установки GTK3
$gtkPath = "C:\Program Files\GTK3-Runtime Win64\bin"

# Добавьте в системный PATH
$currentPath = [Environment]::GetEnvironmentVariable("Path", "Machine")
[Environment]::SetEnvironmentVariable("Path", "$currentPath;$gtkPath", "Machine")

# Проверьте
[Environment]::GetEnvironmentVariable("Path", "Machine") -split ';' | Select-String "GTK"
```

## ✅ Шаг 3: Перезапустите терминал/IDE

**ВАЖНО:** После изменения PATH необходимо:
- Закрыть все открытые терминалы
- Закрыть IDE (VS Code, PyCharm и т.д.)
- Открыть заново

Или перезагрузите компьютер.

## ✅ Шаг 4: Проверьте установку

Запустите скрипт проверки:

```bash

```

Скрипт проверит:
- ✓ Версию Python
- ✓ Установленные Python-пакеты (pandas, weasyprint)
- ✓ Наличие GTK3
- ✓ Работу WeasyPrint


## 🔧 Решение проблем

### Проблема: "Failed to load the libgobject library"

**Решение:**
1. Убедитесь, что путь к GTK3/bin добавлен в PATH
2. Перезапустите терминал (полностью закройте и откройте заново)
3. Проверьте, что используете 64-bit Python (если установили 64-bit GTK3)

### Проблема: Скрипт проверки не находит GTK3

**Решение:**
1. Проверьте путь установки вручную:
   ```bash
   dir "C:\Program Files\GTK3-Runtime Win64\bin\*.dll"
   ```
2. Если путь другой, найдите его и добавьте в PATH
3. Убедитесь, что добавили именно путь к `bin`, а не к корневой папке

### Проблема: PATH добавлен, но все равно не работает

**Решение:**
1. Перезагрузите компьютер (иногда требуется)
2. Проверьте, что добавили в системный PATH, а не пользовательский
3. Убедитесь, что используете правильную версию Python (64-bit для 64-bit GTK3)

## 📞 Дополнительная помощь

Если проблемы остаются:
1. Запустите `check_installation.py` и пришлите полный вывод
2. Проверьте версию Python: `python --version`
3. Проверьте версию GTK3 в папке установки
