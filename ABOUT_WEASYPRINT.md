# Что такое WeasyPrint и зачем нужен GTK3?

## Что такое WeasyPrint?

**WeasyPrint** — это библиотека Python для преобразования HTML/CSS документов в PDF.

### Основные возможности:
- ✅ Преобразует HTML + CSS в PDF
- ✅ Поддерживает современные CSS (flexbox, grid, таблицы, цвета)
- ✅ Работает с кириллицей и другими языками
- ✅ Не требует браузера (работает "головой" без GUI)
- ✅ Создает качественные PDF с точным форматированием

### Зачем он нужен в нашем проекте?

В проекте PDF Checkmaker мы используем WeasyPrint для:
1. **Загрузки HTML-шаблона** (например, `check_template.html`)
2. **Подстановки данных** из CSV/JSON в шаблон
3. **Генерации PDF** из получившегося HTML

**Процесс:**
```
HTML-шаблон + Данные → HTML с данными → WeasyPrint → PDF файл
```

## Почему нужен GTK3?

### Техническая причина:

WeasyPrint использует библиотеки для работы с графикой и шрифтами:
- **Cairo** — для рендеринга графики (рисование линий, фигур, текста)
- **Pango** — для работы с текстом и шрифтами (поддержка разных языков)
- **GDK-Pixbuf** — для работы с изображениями

Эти библиотеки являются частью экосистемы **GTK (GIMP Toolkit)**.

### Почему GTK3, а не GTK4?

- GTK3 — стабильная и широко поддерживаемая версия
- Большинство системных библиотек используют GTK3
- WeasyPrint разработан для работы с GTK3

### На разных операционных системах:

| ОС | Что нужно установить | Почему |
|---|---|---|
| **Windows** | GTK3 Runtime | Windows не включает GTK по умолчанию |
| **macOS** | Cairo, Pango, GDK-Pixbuf (через Homebrew) | macOS не включает GTK по умолчанию |
| **Linux** | libcairo2, libpango (через apt/yum) | Обычно уже установлены или легко устанавливаются |

## Альтернативы WeasyPrint

Если установка GTK3 вызывает проблемы, есть альтернативы:

### 1. **ReportLab** (чистый Python, без системных зависимостей)
```python
from reportlab.pdfgen import canvas
# Но требует ручного создания PDF, нет HTML→PDF
```

**Плюсы:**
- ✅ Не требует системных зависимостей
- ✅ Работает везде

**Минусы:**
- ❌ Нет поддержки HTML/CSS
- ❌ Нужно программировать PDF вручную

### 2. **pdfkit / wkhtmltopdf** (требует wkhtmltopdf)
```python
import pdfkit
pdfkit.from_string(html, 'output.pdf')
```

**Плюсы:**
- ✅ Хорошая поддержка HTML/CSS
- ✅ Простой API

**Минусы:**
- ❌ Требует установки wkhtmltopdf (отдельная программа)
- ❌ На Windows тоже нужны зависимости

### 3. **Playwright / Selenium** (использует браузер)
```python
from playwright.sync_api import sync_playwright
# Открывает браузер, печатает в PDF
```

**Плюсы:**
- ✅ Отличная поддержка современного HTML/CSS
- ✅ Работает как браузер

**Минусы:**
- ❌ Требует установки браузера (Chrome/Firefox)
- ❌ Медленнее (запускает браузер)
- ❌ Больше ресурсов

### 4. **xhtml2pdf / pisa** (чистый Python)
```python
from xhtml2pdf import pisa
pisa.CreatePDF(html, file=open('output.pdf', 'w+b'))
```

**Плюсы:**
- ✅ Не требует системных зависимостей
- ✅ Чистый Python

**Минусы:**
- ❌ Ограниченная поддержка CSS
- ❌ Может некорректно обрабатывать сложные стили

## Почему мы выбрали WeasyPrint?

1. **Качество:** Отличная поддержка CSS и точное форматирование
2. **Кириллица:** Хорошая работа с русским языком
3. **Стабильность:** Надежная библиотека с активной поддержкой
4. **Производительность:** Быстрая генерация PDF без браузера

## Итого

- **WeasyPrint** = инструмент для HTML→PDF
- **GTK3** = системные библиотеки, которые нужны WeasyPrint для работы
- На Windows GTK3 нужно устанавливать вручную
- На Linux/macOS обычно уже установлен или легко ставится

## Если GTK3 не работает

Можно переписать проект на другую библиотеку (например, xhtml2pdf), но это потребует изменений в коде. WeasyPrint — хороший выбор для качественной генерации PDF из HTML.
